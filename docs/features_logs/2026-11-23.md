# Week of 2026-11-23

- **Device-local pairing credentials, clean 401 re-pair UX, and background reconnect pause**:
  - Moved active VM pairing credentials (`vm_host`, `vm_port`, `vm_token`) out of backed-up `herdr_mobile_prefs` into device-local `herdr_mobile_local_prefs` (excluded from Android Auto Backup), with automatic one-time migration for in-place upgrades. Full reinstalls now preserve non-secret SSH profiles without restoring stale bearer tokens.
  - Added `ConnectionState.AUTH_ERROR` for `HTTP 401 Unauthorized` responses so rejected tokens stop auto-reconnecting immediately instead of flashing in a backoff loop, show a **Re-pair** banner/empty-state action that opens `ConnectScreen` in SSH mode when an SSH profile is saved, and skip redundant `GET /api/fs` retries.
  - Paused WebSocket reconnect retry timers while the app is stopped in the background so Android's background network freezer no longer triggers doomed 10-second timeout loops; `onResume()` reconnects immediately on foreground return.
- **Robot "thinking" indicator in chat**:
  - The status line under a streaming reply ("… is thinking…") now shows a robot with a thought bubble that fills with zero to three dots, instead of repeating the same animation as the "Working" badge right above it.
- **Image attachments in chat** ([#75](https://github.com/nedn/agents-term/issues/75)):
  - Added an attach button to the composer of agent tabs with **Take photo** (camera app, no camera permission) and **Choose photos** (system photo picker, including screenshots, no storage permission). Images copied to the clipboard or inserted by the keyboard can be pasted straight into the text field.
  - Attached images upload immediately and show as removable thumbnails above the text field with upload progress and errors. Large photos are scaled to a 2048 px long edge and re-encoded before upload; small screenshots are sent untouched. A message can be images only, up to 8 images.
  - Sent images show as thumbnails in the transcript and open full screen with pinch to zoom. Queued messages and "hold to send now" keep their images.
  - Daemon: `POST /api/tabs/:id/attachments` stores each image (PNG, JPEG, GIF, WebP, BMP; 8 MB cap; type detected from the bytes) in `~/.agents-term/agents_tabs/<tabId>/attachments/` (folder `0700`, files `0600`), and `GET /api/tabs/:id/attachments/:attachmentId` serves it back. Messages refer to images by id; the agent CLI is handed the file paths in its prompt (and `--add-dir` for `claude` and `agy`, so restricted permission modes can read them).
  - Images are deleted with their tab folder when a closed tab expires, when a queued message is removed, and after 24 hours if uploaded but never sent.
  - `/api/info` advertises `attachments` limits; the app hides the attach button on shell tabs and on daemons without attachment support, and older apps keep working unchanged.

  - Updated `daemon-rs/install.sh`, Android SSH bootstrap (`SshBootstrapModels.kt`), default system prompts, UI strings, and systemd user unit (`agentsterm-daemon.service`) to use `~/.agents-term/` and instruct agents to treat it as read-only.
