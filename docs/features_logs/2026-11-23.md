# Week of 2026-11-23

- **Luna theme draws real Windows XP controls** ([PR #68](https://github.com/nedn/agents-term/pull/68)):
  - Title bars use the full Luna gradient with bold, drop-shadowed titles and caption buttons; dialogs are small windows with a blue title bar and a red close button.
  - Buttons are bevelled push buttons (with the pale blue ring on the default one), New tab is the green Start button, switches are check boxes, and text boxes are white wells with a steel-blue edge.
  - The quick tab strip and the connect modes are XP tab controls with the orange cap on the selected tab; the selected drawer row uses the solid blue selection bar.
  - The working indicator is the green marquee progress bar, and the connect screen shows a drawn blue sky over a green hill instead of the dark hero photo.
  - Screens use theme-aware `Themed*` controls (`ui/theme/Controls.kt`, `ui/theme/Dialogs.kt`) that fall back to the Material components, so Midnight and Daylight are unchanged.
- **Selectable app themes, Windows XP look by default** ([PR #67](https://github.com/nedn/agents-term/pull/67)):
  - Added **Settings > Appearance** with four themes: Luna (Windows XP blue gradient title bars, beige windows, squared-off controls, green New tab button), Midnight and Daylight (the previous dark and light palettes), and Match system. The choice applies immediately and is persisted.
  - Luna is the default, replacing the previous follow-the-system dark/light behavior (still available as Match system).
  - Themes are now defined as data (`AppThemeSpec` in `ui/theme/Themes.kt`), and screens read colors, corners and title-bar styling from the theme instead of hardcoding them.
  - The connect screen now has a title bar like the other screens.
- **Finished-task indicators and quick-close actions for persistent tabs** ([`ab05a67`](https://github.com/nedn/agents-term/commit/ab05a67161fd39d5468c80ed45099c87a8fe346d)):
  - Added automatic detection when a coding-agent turn closes by signaling the task is finished and the tab can be closed (`status = "done"`), with client-side fallback for older daemons and automatic reset on follow-up prompts (including queued follow-up messages).
  - Added emerald checkmark icons, `Done` badges, `Task finished · safe to close` hints, a `<N> done` counter, and a one-tap `Close done` button in the Persistent Tabs drawer, plus done indicators in the quick tab strip and top bar.
  - Added `Mark task done` / `Mark as active` toggle in the tab overflow menu backed by `PATCH /api/tabs/:id`.
- **Tab task summaries on tap** ([PR #29](https://github.com/nedn/agents-term/pull/29)):
  - Added per-tab `taskSummary` persisted by the VM daemon: pads the first prompt sent to coding agents (`agy`, `claude`, `codex`) to request a hidden `<tab_task_summary>...</tab_task_summary>` tag, silently strips it from streamed chat output while updating the tab live, and falls back to a cleaned first-prompt summary (also backfilled on daemon startup for existing tabs and derived locally on older daemons).
  - Tapping a tab in the horizontal quick tab strip (or drawer/sidebar) now shows a compact, dismissible Task Summary card below the tab strip with the task summary, status/Done badge, and live status or latest update; tapping the active tab or top bar title toggles it anytime.
  - Updated tab drawer/sidebar rows to display each tab's `taskSummary` instead of only `lastMessagePreview`.
- **Clickable Markdown and bare links in chat** ([PR #17](https://github.com/nedn/agents-term/pull/17)):
  - Rendered `[label](url)` Markdown links and bare `http(s)://` URLs as tappable links instead of raw Markdown syntax, supporting nested bold/italic/inline-code formatting.
  - Web links open in the browser; non-web VM file targets (`file:///path#L10-L20`) render in monospace and copy the decoded VM path with a toast on tap.
