- **Interactive PTY shell tabs with `libghostty-vt`** ([#141](https://github.com/AppEvol/agents-term/issues/141)):
  - Added an opt-in **Interactive terminal (PTY)** mode for Shell tabs alongside the existing default **Command** mode when connected to a capable daemon (`GET /api/info` `pty` capability, persisted per tab as `shellMode: "pty"`).
  - Implemented a Rust daemon Linux PTY session manager (`daemon-rs/src/pty.rs`) and authenticated per-tab WebSocket stream (`WS /api/tabs/:id/pty`) with ordered byte-preserving I/O, window resize (`TIOCSWINSZ`), restart, and a 2 MiB sequenced replay buffer for warm reconnects and cold reattaches.
  - Embedded `libghostty-vt` 1.0.2 on Android via a thin JNI bridge (`app/src/main/jni/ghostty_vt_jni.c`), batched Compose terminal renderer, raw IME input view, mode-synchronized key encoder, bracketed paste with unsafe-paste confirmation, and mobile extra-keys bar (`Tab`, `Ctrl`, `^C`, `Esc`, arrows, `Alt`, `Paste`, `Copy`, `Home`/`End`/`PgUp`/`PgDn`, zoom, keyboard toggle).
