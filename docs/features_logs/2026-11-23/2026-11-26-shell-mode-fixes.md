- **Shell mode reliability, persistent Bash + stdin, exit codes, and picker UX** ([#44](https://github.com/AppEvol/agents-term/issues/44), [#48](https://github.com/AppEvol/agents-term/issues/48), [#49](https://github.com/AppEvol/agents-term/issues/49), [#50](https://github.com/AppEvol/agents-term/issues/50), [#51](https://github.com/AppEvol/agents-term/issues/51), [#53](https://github.com/AppEvol/agents-term/issues/53)):
  - **Working directory validation (#49)**: Expand `~` / `~/...` on the VM, reject nonexistent or non-directory paths at tab creation with actionable 400 errors surfaced inline in `NewTabSheet`, and fail turns explicitly if a tab's directory disappears instead of silently falling back to `$HOME`.
  - **Persistent Bash & interactive stdin (#51)**: Replaced per-command `bash -lc` invocations with a persistent per-tab `bash -l` session (preserving working directory, exported variables, functions, and aliases) with per-turn FIFOs, added `POST /api/tabs/{id}/stdin` (and WS `send_stdin`), and added `Queue` / `Stdin` (+ `EOF`) controls for running Shell commands in the mobile composer.
  - **Exit codes & compact quiet results (#50)**: Recorded `exitCode` independently on Shell messages, eliminated spurious empty code blocks on quiet commands (`true`, `false`, `cd`, `export`), and rendered compact `Exit 0` / `Exit N` badges in the chat transcript.
  - **FIFO Shell queue (#53)**: Drained queued Shell commands one submission at a time so each queued command gets its own turn and exit status even after an earlier `set -e; false`.
  - **New Tab picker & Shell form (#44, #48)**: Changed `"New Agent Tab"` to `"New Tab"`, laid out tab types in a 2-column grid so Shell is visible on portrait phones without horizontal scrolling, switched the sheet heading to `"New Persistent Shell Tab"` when Shell is selected, displayed Shell capabilities, and showed the selected folder basename plus end-positioned path cursor to prevent right-clipping.
