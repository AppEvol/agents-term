- **Rust VM daemon self-update, automatic rollback, and breakglass revert** ([#145](https://github.com/AppEvol/agents-term/issues/145)):
  - Added `agentsterm-daemon update <version>` (strict release tag validation, `curl`/`wget` download, native Rust SHA-256 and `version --hash-only` verification, and `--stage-only` support) and `agentsterm-daemon rollback` (also invocable directly via `~/.agents-term/bin/agentsterm-daemon.prev rollback`).
  - Added bearer-authenticated `GET/POST/DELETE /api/daemon/update` and `POST /api/daemon/rollback` endpoints, `GET /api/info` `selfUpdate` metadata, and WebSocket `daemon_update_status` progress events.
  - Added active-turn deferral (`whenBusy: "defer"` staging to `.agentsterm-daemon.staged` and auto-applying once turns go idle), graceful `axum::serve` shutdown + in-place `execv()` restart preserving PID/token/tabs, anti-clobber `.prev` backups, startup crash-loop guard, and an isolated `rollback-watch` watchdog that automatically restores `.prev` on startup failure.
